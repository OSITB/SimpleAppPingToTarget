# SimpleAppPingToTarget
Легковесная нативная утилита для macOS на базе SwiftUI, которая отслеживает доступность хоста, отправляя серию из 4 ping-запросов в цикле в течение 1 часа до первого успешного ответа.

## Возможности
- **Автоматический цикл проверки:** отправляет по 4 ICMP-пакета (`ping -c 4`) с интервалом в 5 секунд на протяжении 1 часа.
- **Мгновенное оповещение:** автоматически останавливается и подаёт звуковой сигнал, как только хост появляется в сети.
- **Минимализм и нативность:** написано на чистом Swift / SwiftUI без сторонних зависимостей, использует системную утилиту `/sbin/ping`.

## Системные требования
- macOS 13.0 или новее
- Xcode 15.0 или новее

## Сборка и запуск
1. Клонируйте репозиторий.
2. Откройте `PingWatcher.xcodeproj` в Xcode.
3. Убедитесь, что во вкладке **Signing & Capabilities** отключён **App Sandbox** (это необходимо для запуска системного `/sbin/ping`).
4. Выберите свой Apple ID (Personal Team) в разделе **Signing & Capabilities** (платный аккаунт разработчика не требуется).
5. Нажмите `Cmd + R` для запуска или выберите **Product -> Archive**, чтобы экспортировать готовый `.app` файл.
